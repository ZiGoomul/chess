# Chess Highlighter для chess.com

Расширение Chrome (Manifest V3), которое переносит из веб-приложения опции
«Подсвечивать нападения» и «Подсвечивать защиту» на доску chess.com.

- **Нападения** — фигура под боем подсвечивается цветом атакующей стороны
  (синий — белые, оранжевый — чёрные), в правом верхнем углу — число атакующих.
- **Защита** — зелёный счётчик в левом нижнем углу: сколько своих фигур защищают фигуру.

Счёт псевдолегальный: связки и «нельзя королём взять защищённую фигуру» не учитываются.

## Где работает

Анализ (`/analysis`), обзор партий (`/game/.../review`), игра с ботом (`/play/computer`),
уроки, практика, дебюты. На странице партии (`/game/live/<id>`, `/game/daily/<id>`) — только
когда партия уже закончена (на странице есть кнопка «Game Review» или окно результата). В живых и дневных партиях, турнирах и рейтинговых задачах
подсветка выключена: любые подсказки там нарушают Fair Play chess.com и ведут к бану.
Список страниц — в `src/chesscom-board.js`.

## Установка

1. Откройте `chrome://extensions`.
2. Включите «Режим разработчика».
3. «Загрузить распакованное расширение» → выберите папку `extension/`.
4. Откройте chess.com/analysis. Переключатели — во всплывающем окне расширения.
